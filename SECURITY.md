# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting

Report suspected vulnerabilities to [hi@aim.do](mailto:hi@aim.do). Please do
not open public issues for security reports.

ThetaMem is research software. Users remain responsible for sandboxing
untrusted model artifacts, checkpoints, and data files they load with it.
